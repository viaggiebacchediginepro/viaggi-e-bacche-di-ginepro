
# Viaggi e bacche di ginepro

Questo è il tuo sito statico per il blog.

## Come pubblicare il sito su GitHub Pages

1. Crea un account su [GitHub.com](https://github.com) se non ne hai uno.
2. Crea un nuovo repository con nome `viaggi-e-bacche-di-ginepro`.
3. Carica i file `index.html` e `style.css` nel repository.
4. Vai su "Settings" → "Pages" → scegli branch `main` e cartella `/root` (se esiste).
5. Dopo qualche minuto il sito sarà visibile all'indirizzo:
   ```
   https://tuo-nome-utente.github.io/viaggi-e-bacche-di-ginepro/
   ```
   (Sostituisci `tuo-nome-utente` con il tuo username GitHub)

## Come modificare i contenuti

- Modifica `index.html` per aggiornare il testo e i titoli.
- Modifica `style.css` per cambiare i colori, font o layout.
- Puoi creare nuove pagine e linkarle dal menu di navigazione.

Buon blogging!
